# لاحِب

مسابقة توعوية حول **كود الطرق السعودي**، أسئلتها مستخرجة وموثّقة من مجلدات الكود الخمسة والعشرين الصادرة عن الهيئة العامة للطرق.

«اللاحِب» في العربية هو الطريق الواسع الواضح المسلوك.

**على الويب:** https://ghazi-ai.github.io/lahib/ — منشور من هذا المستودع عبر GitHub Pages كما هو، بلا دوكر ولا خادم تطبيقات.

## بطاقات المذاكرة

`study.html` صفحة مراجعة للتحضير قبل المسابقة، تقرأ بنك الأسئلة نفسه:

- **سؤال ← جواب**: تقرأ السؤال، تفكّر، ثم تقلب البطاقة لترى الإجابة والمعلومة والمرجع.
- **جواب ← سؤال**: تظهر الإجابة مع الموضوع والرتبة وتخمّن السؤال.
- تصفية بالرتبة والموضوع، وعلامتا «أعرفها» و«أراجعها لاحقًا» تُحفظ في المتصفح، وجولة مراجعة لما علّمته فقط.
- اختصارات: مسافة للقلب، ١ أعرفها، ٢ أراجعها، الأسهم للتنقل.
- **نسخة PDF** من البنك كاملًا (`data/lahib-bank.pdf`) مصنّفة بالموضوع ثم الرتبة، سؤال وجواب بلا خيارات، مع المعلومة والمرجع لكل سؤال، رابطها في صفحة المذاكرة. تُولَّد بـ `python3 tools/build-pdf.py`.

## قواعد اللعب

**الفريقان واختيار المواضيع** — عدد المواضيع لكل فريق يساوي عدد أفراده، بحد أعلى أربعة:

| أفراد الفريق | مواضيع كل فريق | مواضيع اللوحة | أسئلة الجولة |
|---|---|---|---|
| ٢ | ٢ | ٤ | ٢٤ |
| ٣ | ٣ | ٦ | ٣٦ |
| ٤ فأكثر | ٤ | ٨ | ٤٨ |

يختار الفريقان مواضيعهما بالتناوب من ٢٥ موضوعًا.

**الرتب** — لكل موضوع خانتان من كل رتبة:

| الرتبة | النقاط | طبيعة السؤال |
|---|---|---|
| برونزي | ١٠٠ | معلومة تأسيسية |
| فضي | ٢٥٠ | اشتراط أو قاعدة |
| ذهبي | ٥٠٠ | قيمة دقيقة من الكود |

**وسائل المساعدة** — لكل فريق ثلاث وسائل، كل واحدة **مرة واحدة في الجولة**، ولا يستخدمها إلا **صاحب الدور** في دقيقته؛ الفريق الثاني يجيب بلا وسائل:

| الوسيلة | ما تفعله | متى |
|---|---|---|
| حذف خيارين | يُحذف خياران خاطئان، ويبقى الخياران كذلك للفريق الثاني | حين تكون للسؤال خيارات |
| تبديل السؤال | يتوقف المؤقّت وتُكشف إجابة السؤال الحالي للفائدة العامة بلا نقاط، ثم يضغط المقدّم «اعرض السؤال البديل» فيأتي سؤال من نفس الموضوع والرتبة ويعود المؤقّت | لصاحب الدور قبل أن يجيب |
| طلب مساعدة | ٣٠ ثانية إضافية ويحق لصاحب الدور استشارة الجمهور | في أي سؤال |

**للمقدّم** — على بطاقة نتيجة كل فريق زرّا ± لتعديل النقاط بخطوة ٥٠، لتصحيح اختيار بالخطأ أو تطبيق جزاء.

**دورة السؤال**
1. صاحب الدور: **دقيقة كاملة**، والخيارات الأربعة ظاهرة من البداية.
2. الفريق الثاني: **٢٠ ثانية**، والخيارات ظاهرة أمامه من البداية.
3. **النقاط لصاحب الدور أولًا.** إن أصاب أخذها ولو أصاب الثاني أيضًا؛ وإن أخطأ انتقلت للثاني إن أصاب.
4. يُكشف بعدها الجواب الصحيح ومرجعه في الكود و«معلومة تُثبّت» تشرح سبب الاشتراط.
5. ينتقل الدور للفريق الآخر.

**نمطا اللعب**
- **المسابقة كاملة بخيارات** — كل الرتب باختيار من متعدد.
- **الذهبي بدون خيارات** — البرونزي والفضي بخيارات، والذهبي سؤال مفتوح يجيب عنه الفريق شفهيًّا ويحكم عليه المقدّم بزر صح أو خطأ.

## توسعة بنك الأسئلة

البنك كله في ملف واحد: **`data/bank.js`**. عدّله وحده — اللعبة تقرأ منه مباشرة وتنعكس أي إضافة أو حذف فورًا دون المساس بأي ملف آخر.

### بنية الملف

```js
window.LAHIB_BANK = {
  version: "1.0",
  tiers: [
    { id:"br", name:"برونزي", points:100 },
    { id:"si", name:"فضي",    points:250 },
    { id:"go", name:"ذهبي",   points:500 }
  ],
  topics: [
    {
      id:  "v301",                       // معرّف فريد
      name:"رسم المسار",                  // الاسم على اللوحة
      sub: "التصميم الهندسي للطرق",       // وصف مختصر
      vol: "301",                        // رقم المجلد في الكود
      q: {
        br: [ /* أسئلة الرتبة البرونزية */ ],
        si: [ /* الفضية */ ],
        go: [ /* الذهبية */ ]
      }
    }
  ]
};
```

### بنية السؤال

```js
{
  q:    "ما السرعة التصميمية المرغوبة للطرق السريعة الريفية في التضاريس المنبسطة؟",
  opts: ["140 كم/س", "120 كم/س", "110 كم/س", "160 كم/س"],
  a:    0,                                    // رقم الخيار الصحيح (0 إلى 3)
  ref:  "كود 301 — الجدول (4-1)، ص 59",       // المرجع: المجلد والبند والصفحة
  note: "وهي أعلى سرعة تصميمية في جداول الكود، وتنخفض مع صعوبة التضاريس."
}
```

- **`opts`** أربعة خيارات دائمًا، وتُخلط ترتيبها عشوائيًّا عند العرض.
- **`ref`** إلزامي — هو ما يمنع الخلاف أثناء اللعب ويحوّل اللعبة إلى أداة تعلّم.
- **`note`** هي «المعلومة التي تُثبّت»: سطر يشرح *لماذا* هذا الاشتراط موجود، ويُعرض بعد كشف الجواب.

### إضافة موضوع جديد

أضف عنصرًا جديدًا إلى `topics` بالبنية أعلاه. اللوحة وشاشة الاختيار تتوسعان تلقائيًّا.

### الحد الأدنى

كل رتبة في كل موضوع تحتاج **سؤالين على الأقل** (عدد خانات الرتبة على اللوحة). ويُنصح بأربعة فأكثر ليكون السحب العشوائي ذا معنى ولا تتكرر الأسئلة بين الجولات.

### التحقق قبل الاستخدام

```bash
python3 tools/validate.py
```

يفحص البنية كاملة: عدد الخيارات، صحة رقم الإجابة، وجود المرجع، الأسئلة المكررة، وكفاية التغطية لكل رتبة.

### اختبار منطق اللعبة

```bash
node tools/test-game.mjs
```

٢٦ فحصًا يغطي المؤقّتات، وظهور الخيارات، وقواعد احتساب النقاط، والنمطين، واكتمال الجولة.

## الصور

الواجهة مصمّمة لاستقبال ٣٠ صورة: ٢٥ لبطاقات المواضيع، و٢ لبطاقتي نمط اللعب، و٣ لميداليات الرتب.
ما لم يُرفع منها بعدُ يظهر مكانه إطار ملوّن، فالواجهة تعمل كاملة بصور أو بدونها.

- **`assets/IMAGE-BRIEF.md`** — دليل جاهز لتسليمه إلى ChatGPT: كتلة أسلوب موحّدة، ثم برومبت منفصل لكل صورة بمقاسها ولونها واسم ملفها.
- **`python3 tools/check-images.py`** — يخبرك أي صورة ناقصة وأي مقاس غير مطابق وحجمها الكلي.

| المجلد | العدد | المقاس |
|---|---|---|
| `assets/topics/` | ٢٥ | ‎760×400‎ |
| `assets/modes/` | ٢ | ‎960×400‎ |
| `assets/ranks/` | ٣ | ‎400×400‎ |

> لا تضع نصًّا داخل الصور — النص العربي المولّد يخرج مشوّهًا، وكل الكتابة تأتي من الصفحة فوق الصورة.
